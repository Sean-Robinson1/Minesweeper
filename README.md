# Minesweeper 

A simple implementation of the classic **Minesweeper** game built in Python using the Tkinter.  
Includes adjustable grid size, customizable number of bombs, and a settings menu for a flexible play experience.

I made this program a couple of years ago because Minesweeper was a game I enjoyed playing, but I didn't find that any of the online ones fully suited me, so in classic programmer fashion, I sat down and wrote my own. 

---

## 🎮 Features
- Classic Minesweeper gameplay
- Adjustable grid width, height, and number of bombs
- "Reveal All" option to quickly end a game
- Simple UI built with Tkinter

---

## ⚙️ Controls

- Left Click → Reveal a tile
- Right Click → Place/remove a flag
- Settings Button (☰) → Adjust grid size and bomb count

---

## 🚀 Getting Started

### Prerequisites
- Python3
- Tkinter (comes pre-installed with Python on most systems)

### Run the game
Clone the repository and run the main script:

```bash
git clone https://github.com/Sean-Robinson1/Minesweeper.git
cd Minesweeper
python3 Minesweeper.py
```
